# 本地行为审计

审计分别记录应用读取的接口、请求目标和请求结果。弹窗与命令行分析器共用 `fkclaude.audit.v1` JSONL 事件。

## 使用

1. 在 LSPosed／Vector 中启用 fkclaude，作用域选择 Claude，并完全重启 Claude。
2. 在模块设置页点“打开 Claude 行为审计”，或点 Claude 内可拖动的“审计”入口。
3. 按接口、动作、主机、路径模板和状态搜索，或按类别过滤。点击事件查看完整 JSON。
4. “记录”开关控制采集；“暂停刷新”只冻结列表。关闭弹窗后仍可从入口打开。
5. 导出通过 Android 系统文件选择器保存脱敏 JSONL；清空会先确认。

审计开关与环境覆盖开关独立。停用 LSPosed 模块并重启 Claude 后，两者均停止。环境配置继续使用原有的保存／重启流程。

## 事件语义

| 结果／动作 | 说明 |
| --- | --- |
| `called` | 观察到接口调用；结果另记 |
| `constructed` | 事件结构已构造；`fields` 是已核验字段名，值未读取 |
| `attempted` | 网络调用入口已到达 |
| `blocked` | fkclaude 规则阻止了这次操作 |
| `returned` | 被观察方法正常返回，需要结合观察层解释 |
| `response_received` | HTTP 层取得响应；服务端后续处理仍不可见 |
| `failed` | 调用抛出异常，仅保留异常类型 |
| `queue_result` | beacon 排队结果，见 `phase`；不代表 HTTP 响应 |

同一请求可有多行记录。入队、HTTP 和 socket 写出是不同观察层，不能将各层记录数相加当成独立上传次数。

## 数据保护与容量

每条事件包含本地会话 ID、序号、UTC 时间、单调时钟、进程／线程、类别、动作、来源、结果与脱敏详情。网页记录另带本地文档／视图标识，区分不同页面里的同名请求 ID。

Authorization、Cookie、请求／响应正文、对话文本、联系人内容、位置坐标、设备 ID 原值及任意对象的 `toString()` 不作为日志内容。URL 去除认证信息、查询值和片段；账号、会话及未知路径段转成模板。原生 `peer_address` 保留网络目的地址，用于研究未知流量，不采本机地址和网络缓冲区。

日志保存在 Claude 私有的 `no_backup/fkclaude-audit/`，排除 Android 自动备份。记录器不主动联网。既有 IP 守卫的出口探测标为模块自身活动。

每进程保留 1,000 条内存记录、512 条写入队列和三个 2 MiB 轮转文件。弹窗最多显示 300 条匹配事件；导出为当前进程的内存保留窗口，首行记录范围、淘汰、队列丢弃和写盘错误。状态区显示容量与错误，避免静默截断。

## 覆盖与实验条件

| 层 | 观察范围 |
| --- | --- |
| Android／Java | 设备／标识、运营商、网络环境、应用查询、定位、剪贴板、联系人／日历、传感器、麦克风／相机等接口 |
| Claude 26111218 | 已核验的 OkHttp 汇合点、Sift、产品分析构造与队列；版本不符会记录缺失并保留通用观察 |
| URLConnection | 连接创建、连接、输入／输出流与响应码；不读取或复放 body |
| WebView | 文档开始的 fetch、XHR、beacon、WebSocket 发送及部分网页隐私接口 |
| 原生 socket | connect、send 系列、Internet socket 的 write／writev；目的地址、返回字节和 errno |

WebView 脚本在环境覆盖脚本后注册。页面可自行伪造网页报告，因此这些记录保留页面来源说明。环境配置冻结的对象、Worker、绕开 libc 的直接系统调用、其他 UID／外部浏览器以及未触发功能有可见性边界。Hook 缺失会显示；没有日志不作为没有行为的证明。

原生事件保留捕获时的单调时间和线程，Java 每 500 ms 最多读取 128 条；顶层时间是归入统一日志的时间。原生队列上限 512，溢出／竞争和批次上限会单独报告。关闭记录同步关闭并清空原生待处理队列。写出字节只表示 socket 接受的数据量，不表示服务器已保存。

观察器在被审计进程内运行，同权限代码可以修改或删除日志。这是一套可复核的调试记录，未提供独立可信硬件取证。序号缺口可能来自轮转、丢弃或损坏，需要结合元数据判断。

## CLI 分析

```sh
python3 scripts/audit_logs.py /path/to/audit.jsonl
python3 scripts/audit_logs.py /path/to/audit.jsonl --json
python3 scripts/audit_logs.py /path/to/audit-directory --non-conversation
```

分析器无第三方依赖，检查格式、重复、冲突、序号内部缺口和不完整尾行，分开统计请求阶段、HTTP 响应、阻断与原生字节。它使用进程会话、文档、视图及请求标识联合关联，不将不同页面的 w1 合并。输入和输出均有明确上限，异常或截断返回码 2。
