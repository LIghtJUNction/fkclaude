### 复核命令

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --console=plain
python3 -B -m unittest discover -s tests -p test_audit_logs.py -v
node --test tests/web_environment.test.mjs tests/audit_web.test.mjs
bash scripts/test_native.sh
```

`verify_artifacts.py` 需要本地目标 APK。其 `runtime_hooks_tested=false` 指明检查范围为 DEX 合同与模块打包。设备 Hook 与交互由实测覆盖；原生宿主测试使用测试符号和框架函数表，设备内联补丁属于独立验收层。[E04、E06]
